# JOHN / DIGITAL ORBIT — V3

An art-directed solar-system portfolio built with Next.js, React Three Fiber, procedural 2K planet textures, GPU stars, and custom GLSL shaders. Static cinematic imagery is retained only as an automatic fallback for devices without WebGL.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run start
```
